MyHUB
Interface web para centralizar módulos de gestão pessoal em um único lugar!


Link do projeto: https://pozez.github.io/dev-resource/

Módulos:
O projeto atua como uma shell principal que carrega subaplicações independentes em iFrames.

Sincronização e Autenticação:
A persistência de dados é gerida via Supabase. A autenticação utiliza uma chave de acesso para gerar credenciais internas na plataforma (<chave>@portal.internal), permitindo manter a sessão ativa e sincronizar os módulos.

Como Executar:
O projeto não requer instalação de pacotes ou processos de build.
Clone ou transfira este repositório.
Certifique-se de que os ficheiros dos módulos estão no mesmo diretório que o "index.html".
Abra o ficheiro index.html em qualquer navegador web. o ficheiro index.html em qualquer navegador web.
